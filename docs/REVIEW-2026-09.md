## 设计与动效

首页使用浅色底、石墨文字、蓝色重点，缩短介绍区，让搜索、分类和第一排组件更早出现。主题同时覆盖目录、详情、演示、代码面板、日期控件和识别浮层。

GSAP 通过浏览器就绪后才渲染的独立组件加载，避免 Cloudflare Worker 在模块初始化期间执行计时器。`useGSAP` 管理作用域与清理；进入视口的卡片只做一次小幅位移与淡入。`gsap.matchMedia` 尊重系统减少动态偏好，不劫持滚动。[GSAP React](https://github.com/greensock/react) / [matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/)

## 修复

- `unknown` 识别结果也展示不确定项和追问。
- 浏览第一候选不再自动表示“判断准确”。
- Browser Binding 的快照请求与响应正文均受本地超时约束。
- 能力探测请求增加 10 秒截止时间与卸载取消。
- 本地开发默认关闭远程 binding 连接；按需设置 `WHAT_UI_REMOTE_BINDINGS=true`，生产 binding 声明不变。
- 修复演示中原来依赖深色背景的文字、悬停状态和键盘焦点颜色。
- 附件与多选移除操作保持可预测的焦点位置。

## 依赖安全记录

完整审计最初报告 20 个受影响包。升级兼容补丁后，`brace-expansion`、`postcss` / `nanoid`、`undici`、`browserslist`、`fast-uri`、`js-yaml`、`fflate` 的告警已消除。

**原始 `npm audit` 仍报告 2 个 high 包级告警：`image-size@2.0.2` 以及依赖它的 `vinext@0.0.50`。这不是零漏洞报告。**

截至核对时 `image-size` 尚无修复发布。受影响的 ICNS、JXL、HEIF 解析器在构建配置初始化时禁用；HEIF 包括 AVIF。因此这些格式的静态 import 不再提取尺寸，普通 `public/` 文件仍可原样提供。当前项目资产没有依赖这些静态导入。上传截图走独立 PNG 校验，不进入该构建解析器。

- [ICNS 无限循环公告](https://github.com/advisories/GHSA-w3rx-r6r6-pgpr)
- [JXL / HEIF 无限循环公告](https://github.com/advisories/GHSA-5p2g-fcmc-qvqq)

`npm run audit:security` 打印原始审计结果，仅允许上述两个精确版本、两个精确公告的已评估情况，并实际运行受影响头数据的限时拒绝测试。其他漏洞、版本变化、网络审计失败均使检查失败。该评估于 **2026-10-05 UTC 到期**，届时必须重新核对上游或升级。没有通过主版本迁移或把解析器打包隐藏来制造“审计归零”。
